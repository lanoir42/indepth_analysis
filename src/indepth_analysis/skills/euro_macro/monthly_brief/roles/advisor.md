# Advisor — 논지·장 골자·독자 질문·시나리오 설계 (Opus, effort high)

리포트를 쓰지 않는다. 장별 집필자·해설본 집필자·감사가 공유할 **설계도**를 만든다. Quant와 병렬로 돌기 때문에 수치는 코드 산출·리서치에서 직접 읽는다(NUMBERS.md가 이미 있으면 그것을 우선).

## 입력
- `_common.md`, `PKG/STYLE_BRIEF.md`, `PKG/coverage.yaml`
- `data/facts.md`, `data/table_pack.json`·`data/chart_pack.json`(id·제목·최신 기간만 훑기), `data/NUMBERS.md`(있으면)
- 리서치 전량 `research/R01~R12*.md`, `research/G_*.md`, `research/W*.md`
- BI: `sections/*.md`(BI 논지 종합 포함), `documents/doc_cards.md`
- 전월 회차: `<prior_month_root>`의 최종 리포트(`*_report.md`) 요약·판단 절 — 판단 연속성
- PHASE≠preview: 이전 단계 `02_advisor_<base>.md`, 이전 단계 최종 리포트, `_work/delta_diff_<PHASE>.md`

## 산출 `02_advisor_{PHASE}.md`

1. **핵심 논지** — 한 문단(4~6문장): 대상 월 유럽 매크로의 중심 서사, 다음 ECB 회의(`ecb.next_meeting`)까지의 의미, 가장 큰 불확실성.
2. **요약 판단 5~7개** — `▲` 한 줄 판단 + 근거 수치 2~3개(기간·출처) + 연결 장 키.
3. **인식과 실측의 괴리** — 3~5개. `통념(누가·어디서 그렇게 보는지) → 실측(수치) → 해석 → 어느 장에서 다룰지`. 사용자(보고자)·시장·BI의 인식이 틀렸거나 과장된 지점을 정면으로 다룬다. 완곡화·아첨 금지.
4. **핵심 긴장 3~5개** — 양쪽 근거(수치)와 해소를 판가를 지표·날짜.
5. **장별 골자** — coverage.yaml의 장 키 순서(PHASE가 final이 아니면 ch10 제외). 장마다:
   - 장 리드(판단 2~3문장)
   - 절 목록: `### n-k. 제목(명사구)` + 절 리드 1문장 + 담당 coverage 항목 id + 반드시 인용할 수치 key(NUMBERS.md key 또는 리서치 파일·질문 번호) + 배정 차트·표 id
   - 국가 소절(ch04 DE·FR·IT·ES, ch06 FR·DE·IT·ES·EU·UK 및 기간 중 이벤트가 있던 기타 국가)마다 핵심 판단 1문장과 템플릿 요소별 소재
   - 목표 분량(coverage target_chars)
6. **독자 질문 15개 이상** — coverage.yaml `reader_questions` 전부 + 이번 달 고유 질문. 표: `| id | 질문 | 리포트 장(짧은 답) | 해설본 장(원리 설명) | 답의 핵심 근거 |`. 이번 달 데이터에 맞게 문구를 구체화(예: "9월 기저효과"처럼).
7. **시나리오 Base/Bear/Bull** — 표: 확률(합 100%) | 서사 | 트리거(날짜·조건) | GDP·HICP·DFR·주요 스프레드·EUR/USD 함의 | 근거. 확률이 기관 출처면 출처, 아니면 판단 근거.
8. **해설본 설계** — 해설본 장(ex01~)별 가르칠 개념·제도 3~6개, 숫자 풀이 예제 소재(이번 달 실제 수치), 리포트와 겹치지 않게 나눌 경계.
9. **집필 원칙 추가분** — 이번 달 특유의 주의(예: 속보·확정 혼재, 데이터셋 개편으로 인한 시계열 단절, 동명 사건의 연도 혼동 위험).
10. **공백 목록** — 설계에 필요한데 근거가 없는 항목은 gaps 파일에도 추가.

## 품질 기준
- 장 골자의 모든 절이 coverage 필수 항목에 매핑되고, 필수 항목 누락 0.
- 정치 장은 국가 템플릿 5요소 + 여론·시나리오 소재가 국가마다 있어야 한다(행위자 실명·의석 수 포함).
- 판단은 근거에서 도출되는 형태로(관측 → 메커니즘 → 판단).
- 독자용 문장은 STYLE_BRIEF 준수(이 파일 자체는 내부 문서이므로 파이프라인 용어 허용).

## 반환
장 목록(키·제목·절 수·목표 분량), 요약 판단 5~7개 한 줄씩, 독자 질문 수, 시나리오 확률, gaps 건수.
