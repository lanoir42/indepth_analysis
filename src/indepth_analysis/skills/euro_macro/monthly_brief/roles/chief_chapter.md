# Chief — 리포트 장 집필 (Opus; effort는 coverage.yaml `effort_policy`: ch02·ch06·ch09 high, 나머지 medium)

장 하나당 에이전트 하나. 워크플로가 `CHAPTER=<coverage 장 키>`를 넘긴다. 분량이 큰 장(ch06 정치, 필요 시 ch04)은 `SUBSECTION=<국가 코드>`로 쪼개 병렬 집필할 수 있다.

## 입력
- `_common.md`, `PKG/STYLE_BRIEF.md`(필독), 문체 실물 예시(KCIF 파일), `PKG/coverage.yaml`의 해당 장
- `02_advisor_{PHASE}.md`의 해당 장 골자·인식 괴리·독자 질문 배정·시나리오
- `data/NUMBERS.md`의 해당 장 절(수치 1순위), `data/facts.md`
- 해당 장 리서치(장↔축: ch02→R01·W2, ch03→R02, ch04→R03·W1, ch05→R04·R05, ch06→R06·R07·R08·R09·R11, ch07→R10·R09, ch08→R11, ch09→R12·전 축, ch01→전 축 핵심 발견), `research/G_*.md`
- 관련 BI `sections/<GROUP>.md`의 `BI 논지 종합`
- PHASE≠preview이고 워크플로가 `BASE_DRAFT=`(이전 단계 최종 리포트의 같은 장)를 주면: 유효한 문장·구조는 유지하고 새 데이터·사건으로 갱신(낡은 수치 교체, 뒤집힌 판단은 새 근거로 재서술). 이전 단계와의 비교 서술은 ch10 몫이므로 이 장에서는 쓰지 않는다.

## 산출
- `drafts/{PHASE}_report_{CHAPTER}_r1.md` (SUBSECTION이 있으면 `drafts/{PHASE}_report_{CHAPTER}_{SUBSECTION}_r1.md`)
- 첫 줄 주석 `<!-- chapter: {CHAPTER} | subsection: {SUBSECTION|-} | chars: N -->` (N = 공백 포함 글자 수, 주석 제외)
- gaps 파일(_common 4절)

## 형식
- 장 제목 `## {번호}. {coverage title의 이름}` (SUBSECTION 집필 시에는 `### {번호}-{k}. {국가}: {주제}`로 시작하고 장 제목은 쓰지 않음)
- 장 리드 `**[판단]**` 2~3문장 → 절(`### n-k. 명사구`)마다 `**[판단]**` 리드 → `- **(소주제)**` 불릿 2~3문장 → 세부·인용 들여쓰기(STYLE_BRIEF 2절)
- 차트·표 참조: 해당 불릿 뒤 별도 줄에 `[차트: <chart_id>]`, `[표: <table_id>]` — NUMBERS.md 배정 id만. 표를 새로 만들 때는 진짜 비교(국가 매트릭스·시나리오·일정)에 한하고, 값은 NUMBERS.md에서만.
- 장 끝에 소결 불릿 2~4개(`**(시사점)**`, `**(관전 포인트)**` — 날짜 포함).

## 장별 필수(coverage.yaml 항목 전부 + 아래)
- **ch02**: 성명·기자회견·의사록 원문 인용(영문+번역), 위원 5명 이상(목표 8명) 발언 지형표, 스태프 전망 전 연도·직전 회차 대비, OIS 경로 비교, TPI 요건과 프랑스 스프레드의 관계, 다음 회의 시나리오.
- **ch03**: 기여도 표 참조, 기저효과 월별 방향, 임금이 물가에 상방인지 하방인지 명시적 판정.
- **ch04**: DE·FR·IT·ES 국가 소절 각 1,500자 이상, 순수출·재고 인과, PMI vs 산업생산 괴리 판정(일시 요인 vs 추세).
- **ch05**: 신용·은행·주택 소절 필수, EUR/USD·EUR/KRW 동인 분해.
- **ch06**: 국가별 템플릿(행위자 → 의회 산술 → 사건 일지 → 정책 내용 → 시장 전달경로 → 여론 → 시나리오·트리거) FR·DE·IT·ES·EU·UK 전부, 기타 이벤트 국가 3~6불릿씩. 총 12,000자 이상. 불신임·예산 표결은 필요 표 수를 계산해 보여 준다.
- **ch09**: 시나리오 표(확률·트리거·함의), 기관 전망 비교 표, 다음 30일 관전 일정과 각 이벤트가 흔드는 판단.

## 품질 기준
- 목표 분량 ±15%. 분량을 채우려는 반복·수식어 금지 — 모자라면 메커니즘 설명과 국가·행위자 디테일로 채운다.
- 모든 판단 불릿은 관측(수치·날짜) → 메커니즘 → 판단의 순서가 보여야 한다.
- 독자 질문 중 이 장에 배정된 것은 본문에서 짧게 답한다(원리의 긴 설명은 해설본 몫).
- 거부·유보 문장 0, 금지 토큰 0(_common 5절 grep 실행 후 저장).
