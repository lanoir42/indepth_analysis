## 4. 문체·발표 검수

낭독 대본과 학습 해설의 구분은 사용자 목적에 부합하므로 체언형·3줄·개조식을 기계적으로 강제하지 않음. 문답의 의문형 제목도 실제 질문 대비 목적에 부합. 필요한 기술 구별을 담은 부정문은 삭제 대상이 아님. 분량·링크 수를 내용 완성으로 주장하는 문장은 이번 정본에서 발견하지 않음.

문체의 실제 수정 대상은 R-M5의 작업 자기보고, R-M3의 집필 지침, 318행 ‘정책 저장소에 대한 쓰기 권한을 에이전트가 가져서는 검사 규칙을 스스로 바꿀 수 있다’의 어색한 조건 표현. 마지막은 ‘에이전트가 정책 저장소 쓰기 권한까지 갖고 있으면 검사 규칙을 스스로 바꿀 수 있다’로 교정 가능.

37~39분은360자/분과 도표3~5분의 가정으로 명시되어 실측을 주장하지 않음. 본 감사도 실제 소요시간을 판정하지 않음. 다만 위 보강을 낭독 본문에 추가하면 기존 추정 시간은 재산정 필요. 장문의 심화 설명을 모두 대본에 넣을 필요는 없으며 핵심 경로는 대본, 추가 수치·구현은 같은 파일의 해설로 배분 가능.

본문의 기술→구매→수익→투자 연결은 원장표를 무조건 추종하지 않고 별도 조건을 설명하고 있음. 해당 경계는 수정 과정에서도 유지할 것. 30분을 맞추려고 투자 조언·계좌/호가 조사로 확장할 필요 없음.

## 5. 재검토 종료 조건

R-H1과R-H2를 실제 본문에서 해소한 뒤 재감사. MEDIUM은 같은 수정에서 반영 권고. 보강 후에는 사건 수치가 조사파일과 일치하는지, 자기보고를 기술 설명으로 바꾸면서 불확실성의 근거를 삭제하지 않았는지, 낭독시간 추정이 바뀌었는지 확인.

원문 PDF·정본을 수정하지 않았으며 본 감사 파일만 추가. 이 판정은 독자 이해·논리·문체 감사이며 제품 실기 시험·외부 출처 전수 재검증을 대신하지 않음.
