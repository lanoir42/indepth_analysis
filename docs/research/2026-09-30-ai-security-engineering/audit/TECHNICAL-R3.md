## 숫자·과장 확인 결과

1. §7.3의 오프라인 감독기 약 1% → CoT 제거 시 약 50%, auto-mode의 행동 거부 66%를 [Anthropic 원문](https://www.anthropic.com/research/alignment-assessment-cybersecurity-incidents)의 Replay with monitors 부분과 다시 대조했다. 값과 행동 단위가 일치한다. 서로 다른 입력·사후 시험이며 운영 예방률이 아니라는 현재 한정도 적절하다.
2. §7.6의 0.55/0.45 결합식은 [Constitutional Classifiers++ v1 §6](https://arxiv.org/html/2601.04603v1)의 최종 시스템과 일치한다. R2에서 확인한 5.5% 이관·0.05% flag·1,736시간·약 19.8만 시도·40배 검사 계산량 비교도 변하지 않았다. 완전 무우회나 전체 모델 40배 가속으로 확대하지 않는다.
3. §2.1의 ‘탈취한 클라우드 역할로 시도한 변경 API 호출’ 표현은 이전의 ‘클라우드 역할 변경 요청’보다 정확하다. IAM이 막은 대상과 탈취된 권한을 혼동하지 않는다.
4. §5.4는 MCP의 버전 고정·승인 해시를 저자 설계로 구별한다. §6.4는 PCC의 기밀성 구조와 모델 행동의 정확성을 분리한다. 이 추가 본문에서 즉시 드러나는 완전 보장 주장은 발견하지 않았다. 해당 제품 전체를 새로 감사한 판정은 아니다.
5. 새 AI Control·Factor 표는 시험·배포 시나리오와 환산 유용성을 본문에 명시하고 직접적인 제품 사고율로 제시하지 않는다. 이번 종결 검수에서는 이 논문들을 새로 전수 재검증하지 않았으며 별도 연구 담당의 원문 검증을 대체하지 않는다.

## 남은 LOW 명료화 권고 — 적용 여부와 무관하게 핵심 감사 종결

- §7.6의 ‘2025년 12월~2026년 1월 운영 트래픽 병행 시험’은 ‘2025년 12월 1일~2026년 1월 1일 shadow deployment(병행 평가)’로, ‘최종 거부 비율’은 ‘거부 대상으로 표시한 비율’로 쓰면 더 명확하다. 원문도 refusal rate라는 표현을 함께 사용하므로 현재 서술을 사실 오류로 판정하지 않는다.
- 같은 절의 ‘기준 수준’은 ‘무방어 모델의 절반 이상 상세도를 평가 루브릭으로 충족’으로 풀어 쓰면 독립적인 설명이 된다. 현재 문장도 보편적 우회의 제한된 정의를 명시하므로 과장 판정은 아니다.
- §13.1 714행의 ‘종단간 보장이 생긴다’는 ‘종단간 통제의 전제가 마련된다’로 바꾸면 형식 보장과 일반 통제를 더 선명하게 구분한다. 바로 뒤에서 연결 실패 가능성을 설명하므로 현재 문맥에서 충분조건을 단정한 HIGH 주장으로 보지 않는다.
